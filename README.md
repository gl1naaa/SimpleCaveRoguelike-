# Simple Cave Roguelike

**Roguelike-подземелье в терминале на Python**

---

## О игре

**Simple Cave Roguelike** — это текстовый roguelike с процедурной генерацией подземелий, богатой боевой системой, прокачкой и кучей лута. Вся графика отрисовывается в терминале с помощью ANSI-цветов и символов Unicode.

Спуститесь на 10 этажей подземелья, собирайте снаряжение, изучайте навыки, нанимайте союзников и победите финального босса!

## Особенности

- **Процедурная генерация** — каждый этаж уникален: комнаты, коридоры, ловушки, сокровищницы
- **6 классов** с уникальными навыками и стилями игры
- **30 навыков** с перезарядкой, затратой маны и статус-эффектами
- **Система полей зрения** — видите только то, что освещено; исследованные области отображаются приглушённо
- **7 уровней редкости предметов**: common → uncommon → rare → epic → mythic → legendary → unique
- **14 уникальных (мемных) предметов** — Banana Peel, Plot Armor, D20 of Fate, Rubber Duck и другие
- **Полная система экипировки** — 9 слотов: оружие, шлем, нагрудник, поножи, ботинки, перчатки, ожерелье, 2 кольца, плащ
- **NPC-враги** — враждебные персонажи с классным ИИ (появляются с 2 этажа)
- **NPC-союзники** — наймите помощников в городе, они следуют за вами и сражаются
- **Стартовая группа** — в начале каждого забега появляется случайная пачка из 1–2 союзников; целитель в группе может быть только один
- **Город Убежище** — безопасный хаб между этажами с магазинами и алтарём исцеления
- **Боссы с фазами** — при потере HP боссы ускоряются и становятся опаснее
- **Дальние монстры** — скелеты-лучники, огненные, ледяные и тёмные маги
- **Тактические монстры** — стайные охотники, каменные стражи, ядовитые преследователи и кровавые культисты
- **Статус-эффекты** — горение, замедление, оглушение, отбрасывание, вампиризм, уклонение, щит, бафф
- **Система поиска пути** — BFS-ИИ для NPC: преследование, бегство, кайтинг, фланкирование
- **Настройка через JSON** — все параметры баланса доступны в config.json
- **Меню настроек** — изменяйте любые параметры прямо из главного меню
- **Автоматическая атака** — подойдите к врагу, чтобы нанести удар
- **Случайный лут с врагов** — монстры могут оставлять случайное оружие, броню, аксессуары и расходники
- **Межзабеговая прогрессия** — Dungeon Points, постоянные бонусы HP/MP/ATK и стартовое зелье сохраняются в `meta_save.json`
- **История забегов** — результаты последних 50 попыток сохраняются в `src/run_history.json`

## Город Убежище

Между этажами вы попадаете в безопасный город:
- **Магазины** — покупка оружия, брони и расходников за золото
- **Алтарь исцеления** — восстановление HP и MP
- **Найм NPC** — нанять союзников (мечника, лучника, мага, целителя, разбойника)
- **Лестница вниз** — спуск на следующий этаж

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Перемещение по подземелью |
| Пробел | Взаимодействие (лестницы, сундуки, события, магазины) |
| Z X C V B | Использование навыков |
| E | Открыть инвентарь |
| Del | Выбросить предмет из инвентаря |
| ESC | Пауза / Выход в меню |
| 1-9 | Выбор предмета в магазине |
| Space | Купить предмет / Экипировать / Снять / Нанять союзника |
| Delete | Уволить последнего нанятого союзника в таверне |

## Конфигурация

Все параметры игры настраиваются через `src/config.json`:

- **display** — разрешение экрана, FPS, шрифт
- **map** — генерация подземелья
- **player** — базовые характеристики игрока
- **combat** — урон, криты, выпадение золота
- **rarity** — веса выпадения и множители статов
- **weapons** / **armor** — базовые характеристики оружия и брони
- **npc_enemies** / **npc_ai** — поведение NPC-врагов
- **party** — параметры союзников
- **fov** — поле зрения
- **colors** — все цвета интерфейса

## Структура проекта

```
SimpleCaveRoguelike/
├── play.bat            # Лаунчер
├── CHANGELOG.md        # История изменений
├── src/
│   ├── main.py         # Точка входа, настройка терминала
│   ├── game.py         # Главный игровой цикл, рендер карты, город

│   ├── config.json     # Все параметры игры (настраивается пользователем)
│   ├── settings.py     # Меню настроек в игре
│   ├── entities.py     # Игрок, монстры, боссы, союзники, NPC-враги, NPC-союзники
│   ├── combat.py       # Боевая система, снаряды, статус-эффекты
│   ├── items.py        # Предметы, генерация лута, уникальные предметы
│   ├── skills.py       # 30 навыков всех классов
│   ├── inventory.py    # Инвентарь и экипировка
│   ├── npc_ai.py       # ИИ NPC-врагов и союзников (классное поведение)
│   ├── pathfinding.py  # BFS поиск пути, бегство, фланкирование
│   ├── map_generator.py# Генерация подземелий и города
│   ├── fov.py          # Поле зрения
│   ├── input.py        # Обработка ввода (WASD, клавиши)
│   ├── ui.py           # Утилиты отрисовки (цвета, символы)
│   └── menu.py         # Экраны меню, выбор класса, экран смерти
```
