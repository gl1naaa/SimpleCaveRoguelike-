# Simple Cave Roguelike

**Roguelike-подземелье в терминале на Python**

---

## О игре

**Simple Cave Roguelike** — это текстовый roguelike с процедурной генерацией подземелий, боевой системой, прокачкой и богатым лутом. Вся графика отрисовывается в терминале с помощью ANSI-цветов и символов Unicode.

Спуститесь на 10 этажей подземелья, собирайте снаряжение, изучайте навыки и победите финального босса!

---

## Классы персонажей

| Класс | Оружие | Описание |
|-------|--------|----------|
| **Swordsman** | Меч | Танк ближнего боя. Высокий STR и HP. Умения: Cleave, Whirlwind, Shield Bash, War Cry, Berserk |
| **Archer** | Лук | Дальнобойный DPS. Высокий AGI и криты. Умения: Quick Shot, Volley, Poison Arrow, Frost Arrow, Arrow Rain |
| **Mage** | Посох | Стеклянная пушка. Высокий INT и заклинания. Умения: Fireball, Chain Lightning, Blizzard, Mana Shield, Blink |
| **Summoner** | Сфера | Универсал. Все характеристики усиливают союзников. Умения: Raise Dead, Spirit Drain, Fire Nova, Bone Wall, Army of Dead |

---

## Особенности

- **Процедурная генерация** — каждый этаж уникален: комнаты, коридоры, ловушки, сокровищницы
- **Система полей зрения** — видите только то, что освещено; исследованные области отображаются приглушённо
- **7 уровней редкости предметов**: common → uncommon → rare → epic → mythic → legendary → unique
- **Уникальные предметы** — мемные и необычные штуки вроде «Banana Peel», «Plot Armor», «D20 of Fate»
- **5 слотов навыков** (Z/X/C/V/B) с перезарядкой и затратой маны
- **Система призванных союзников** — скелеты, призраки, огненные духи с прокачкой
- **Боссы с фазами** — при потере HP боссы ускоряются и становятся опаснее
- **Инвентарь** с экипировкой, зельями и книгами навыков
- **Автоматическая атака** — подойдите к врагу, чтобы нанести удар

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Перемещение по подземелью |
| Пробел | Взаимодействие (лестницы, сундуки, события) |
| Z X C V B | Использование навыков |
| E | Открыть инвентарь |
| ESC | Пауза / Выход в меню |

---

## Требования

- **Python 3.8+**
- **Windows** (для полноценной работы ANSI и шрифтов)
- Терминал с поддержкой ANSI/VT100 (Windows Terminal, cmd с chcp 65001)

---

## Запуск

```bash
cd rogue_py
python src/main.py
```

Или через `play.bat` (автоматически разворачивает окно и настраивает шрифт):

```
play.bat
```

## Структура проекта

```
rogue_py/
├── play.bat            # Лаунчер
├── src/
│   ├── main.py         # Точка входа, настройка терминала
│   ├── game.py         # Главный игровой цикл, рендер карты
│   ├── config.py       # Конфигурация (размеры, баланс, цвета)
│   ├── entities.py     # Игрок, монстры, боссы, союзники, сундуки
│   ├── combat.py       # Боевая система, снаряды, эффекты
│   ├── items.py        # Предметы, генерация лута, уникальные предметы
│   ├── skills.py       # Навыки всех классов
│   ├── inventory.py    # Инвентарь и экипировка
│   ├── map_generator.py# Генерация подземелий
│   ├── fov.py          # Поле зрения
│   ├── input.py        # Обработка ввода (WASD, клавиши)
│   ├── ui.py           # Утилиты отрисовки (цвета, символы)
│   └── menu.py         # Экраны меню, выбор класса, экран смерти
```
